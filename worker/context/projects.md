# Nimish Vishnoi — Projects

## Selected projects

### ESI Synthesis — 2020

A logistics and commercial application used by Oil and Gas companies to manage
their order-to-cash cycle. Technologies: C#, ASP.NET, SQL Server, and
JavaScript.

### L & L Automotive — 2019

An automotive catalog website for browsing and filtering vehicles by model,
built during Nimish's time at Wildnet using .NET MVC, jQuery, and SQL Server.

### Bizzalley — 2019

A customer engagement platform that helps businesses connect with prospects and
manage customer inquiries. Technologies included .NET MVC, APIs, Firebase,
JavaScript, and SQL Server.

### ClicFlyer — 2018

A flyer and promotional-offer management platform developed at Wildnet using
.NET MVC, APIs, jQuery, and SQL Server.

### Anomaly Detection in Data Center — 2018

A Python and machine-learning project that identified unexpected items or events
in datasets using unsupervised learning algorithms.

### MAC Verification App — 2017

An Android application that verified a device MAC address against a backend
database to prevent unauthorized app distribution. Technologies included
Android, PHP, MySQL, APIs, and Bootstrap.

### College Fest Website — 2017

A website for the Gyan Jyoti annual college fest, used for event registration
and publishing schedules and event details. Technologies included PHP,
JavaScript, MySQL, and Bootstrap.

### BBMS — 2017

A blood bank management system for maintaining stock and donor/receiver records,
delivered as both desktop and web applications using Java and MySQL.
